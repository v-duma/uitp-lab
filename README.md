# Student Deadline Manager

[![CI/CD Pipeline](https://github.com/v-duma/uitp-lab/actions/workflows/ci-cd.yml/badge.svg)](https://github.com/v-duma/uitp-lab/actions/workflows/ci-cd.yml)

**Live Demo (Production):** [https://uitp-lab.vercel.app/](https://uitp-lab.vercel.app/)

## Про проєкт
Цей проєкт є MVP застосунку для управління студентськими завданнями та дедлайнами. 

В рамках лабораторної роботи було налаштовано:
- **Continuous Integration (CI):** Автоматична перевірка коду лінтером та запуск модульних тестів за допомогою GitHub Actions.
- **Continuous Deployment (CD):** Автоматичне розгортання (деплой) артефакту збірки на платформі Vercel після кожного успішного злиття в головну гілку.
